# V6 measurement protocol — technical pilot contract

Status: v6 pilot output contract; full production measurement extension still pending. No simulation equations changed.

## Definitions and units
- A: structural opportunity (edge list and uniform-use baseline, topology); Lambda: expected substantive selection mass, even on audit periods (NOT audit sampling probability). X / realized_reliance: observed sampling allocations, not guaranteed delivered messages under mute/null. For a source with probability pi, inclusion = 1-(1-pi)^C computed at the citizen level, then averaged. Audit uses its own equal diagnostic allocation.
- Q: absolute cumulative incoming added evidence precision by immediate source class; W: per-citizen Q share, averaged over citizens (not ratio of aggregate Q unless explicitly labeled). I: fraction of substantive-learning periods with positive precision for source class, not requests. W and Q are accounting not causal influence or upstream provenance.
- Loss: MSE to truth 0, squared mean error plus within-group population variance (ddof=0), total loss under sender and matched null; D = MSE(sender)-MSE(null) within seed, structure, receiver. Null slot inactive after t0 and ranked last: D includes competitive changes.
- High-H minus low-H and high-gateway minus low-gateway. Primary puzzle high-S group +1 fixed-biased adaptive: paired delta W_jammer, delta Q_jammer, delta W_same_peer, delta MSE. Report all groups and receiver conditions; fraction of seeds with delta W<0 AND delta MSE>0, plus absolute Q counterpart. Do not condition on sign to select results. Separate changes in bias and variance. Gateways use role (not arbitrary group label) for gateway/non-gateway outcomes.

## Outputs of run_v6_pilot
One gzipped JSON shard per seed/suite, with explicit experiment, cell, sender, reliance, seed, run_id. Consolidated CSV.gz files and shareable ZIP. All run_condition records retained except raw edge logs (summarized into group/role acquisition rows at checkpoints; raw edges retained in shards); citizen-level early event traces retained (technical t0–1) and terminal beliefs/precision. Group terminal rows combine citizen beliefs with Q/W/I. Acquisition group records compute expected source mass and inclusion probabilities from checkpoint edge lists per ego, and realized request shares; split by actual learning target where appropriate. Run-level evidence checkpoints include A-uniform/Lambda/W gateway summaries. Rank diagnostics are pre-period; belief/precision checkpoints are post-period: do not conflate horizon_step with pre-update rank. At t0 all audit, t1 pre-period acquisition is after first audit. Sender history stored as emitted, not inferred from boolean active.

## Validation before scientific interpretation
Complete expected cells per seed, fixed horizon finite MSE and citizen states, common initial state within prior, graph matching within cell across sender/reliance and M/S/L; terminal citizen count N; MSE decomposition; nonnegative Q and normalized W (zero if no evidence), zero null Q_jammer, zero muted Q_peer. Technical event count N*2 per run, t0 no theta change (existing instrument), exact M/S/L t0 signature equality within seed/sender/receiver, muted t1 zero delivery. Frozen policy constant from t1 at recorded checkpoints. Technical logger on/off parity with representative run per seed/suite. Gate PASS is technical only; no scientific promotion by sign. Save all results. Actual local execution is required; code inspection alone does not validate behavior.

## Analysis
Use seed as unit; 10,000 paired whole-seed bootstrap draws fixed seed 20261124; MCSE SD/sqrt(n), paired signs, no inference to real population. Report complete conditions; group membership fixed across H treatment. Compare high vs low gateway A uniform peer-conditional share vs Lambda/W peer-conditional share (same denominators). Report T=200 vs 400 from same trajectories when available. Never pool legacy and v6. Parse CSV literal null with keep_default_na=False.

## Limits / production gate
Current pilot exposes terminal subgroup MSE and Q/W/I, population time path, sparse group acquisition and subgroup Q/W/I checkpoints. It does not expose complete subgroup belief trajectories, source-specific credibility trajectory for every class, or full-horizon realized requests by group. Add/test a passive observer for these before final production if needed; no behavior changes. No exhaustive event dump required. Early audit equality checks in this pilot do not independently prove every late delivery invariant. Archive raw shards, not just summaries.
