## Common model (explicit settings)
- N=100 citizens + Expert (position 0) and Jammer (position 1); truth 0, Expert location 0, Jammer underlying location 4. Initial SDs 1,1,5 (citizens). Initial perceived displacement mean 0, SD 5. Fixed-horizon synchronous updates; cautious learning, delta_comparison, equal audit requests.
- C=20, epsilon=.05, recursive rank selection; for d sources ranks r<d have (1-epsilon)epsilon^(r-1), last rank epsilon^(d-1). Credibility changes acquisition, not direct debiasing or precision discount. p_t=1/(t+1), audit OR substantive learning; t=0 all audit, no substantive update. Approximately 6.57 expected audits per 400 steps.
- source_posterior, tau_social=1. Same peer's repeated draws form one source observation, variance sender snapshot posterior SD squared + tau_social squared. External independent draws have variance sender snapshot SD squared / request count delivered. MIN_SD=1e-8; variance floor squared. Distinguish cumulative immediate-source precision from origin/provenance.
- initial_audit_mode=centroid, frozen_ranking_mode=first_audit. t0 nonstrategic belief-consistent centroid for all senders (not necessarily truthful), strategic refresh t1,6,11,... for interval 5. Frozen fixes ranking after audit; adaptive may subsequently revise. Prior t0 behavioral rank is seeded/shuffled with null last, NOT pre_disruption ranking from source locations. Never present old initial rank probabilities as new ones. t1 pre-update is post-audit accessibility.
- Sender regimes explicit, never infer from boolean jammer_active: null retains structural slot, participates in t0 audit then inactive, last rank; fixed_biased constant position 4 after audit; adaptive bounded myopic posterior gain; credibility_aware one-step proxy, lambda=1. Null is not truth_clone. D includes change in competition as well as messages. No claim of globally optimal strategic policy.
- K=1, surveillance interval=5 in pilot. The invited abstract's audience segmentation/surveillance comparisons are not covered by this grid; retain a separate targeted strategic scope audit. K>1 and alternate refresh intervals exist but are not yet approved production settings.
- Myopic objective mean_i[(1-k_i)mu_i+k_i*m-theta]^2 - (m-mu_D)^2, k_i=sigma_i^2/(sigma_i^2+1). Credibility-aware multiplies damage by (1-p_t)q_i and subtracts lambda*p_t*mean_i[a_i*((1-eta_i)b_i+eta_i*(m-mu_i))^2]; q_i=1-(1-pi_i)^C if accessible, a_i=min(1,C/d_i) if accessible, eta_i=v_i^2/(v_i^2+sigma_i^2+1/max(1,C/d_i)), as specified in GATE0C_CREDIBILITY_AWARE_PROTOCOL_2026-11-23.md. Full-cluster means, zero exposure if unavailable. It uses more recipient information (rank and credibility) than myopic; not an isolated intelligence change. Lambda=1 is a conventional equal-unit setting, not empirically calibrated.
