# Experiment III 500-Seed Audit — Pre-Posterior-Gain Jammer

## Status

This audit records the first 500-seed Experiment III production run
(`design_id=49dd116672e5`) under the now-superseded Jammer response rule that
used cross-sectional segment dispersion as the one-step response gain.

The run is retained as diagnostic evidence only. It is not a manuscript result.

## Computational gate

The production grid completed:

```text
500 matched seeds
x 2 redundancy levels
x 2 reliance modes
x 2 Jammer states
= 4,000 T=200 runs
```

The executable gate passed:

- all 4,000 runs finite;
- all runs reached T=200;
- low/high local two-step Expert-route counts were exactly 1/2 for
  non-gateway citizens;
- frozen Lambda dynamics were invariant.

The largest terminal MSE was nevertheless 197.621, so finite-state completion
was not sufficient to establish dynamic stability.

## Why this is not treated as an ordinary heavy-tail result

Under the old Jammer rule,

```text
kappa_g = s_g^2 / (s_g^2 + 1),
```

where `s_g` was cross-sectional disagreement.

As beliefs spread apart, `kappa_g -> 1`, causing the closed-form objective
denominator `1-kappa_g^2` to approach zero. The resulting message then
increased disagreement further.

This mechanism is not a property of Gaussian citizen updating: the uncertainty
that governs one citizen's response to a new observation is that citizen's
posterior variance, not the cross-sectional variance of citizen means.

The problem is also distinct from the numerical posterior-SD floor. Seed 2173's
runaway was generated by the Jammer curvature channel.

## Resolution

The canonical model now uses

```text
kappa_i = sigma_i^2 / (sigma_i^2 + 1)
```

for each citizen's current posterior SD and chooses one common message mean per
segment:

```text
m_g*
  = { E[kappa_i((1-kappa_i)mu_i-theta)] + mu_D }
    / { 1 - E[kappa_i^2] }.
```

With the primary initial citizen SD of five, Gaussian state updating weakly
reduces posterior uncertainty, so:

```text
max kappa_i <= 25/26
1 - E[kappa_i^2] >= 51/676 ~= 0.07544.
```

No clipping or new strategic cost parameter is introduced.
