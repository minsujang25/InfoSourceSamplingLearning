# Reconstruction Round 2 Diagnostic Audit

## Status

The full 80-run matched diagnostic completed successfully under commit
`f0c5f04efe052718beaf1ba67239311a6f1d15b8`.

Design:

```text
4 network environments
x 2 Jammer states
x 2 reliance modes
x 5 matched seeds
x flat initial beliefs
= 80 runs
```

Each run used 100 citizens, K=1, epsilon=.05, credit=20, and an exact
fixed horizon of T=100.

This is a scientific diagnostic, not a substantive result set. Five seeds are
insufficient for manuscript inference.

## Gate 1: finite-state stability — PASS

All 80 runs completed with finite citizen states.

```text
all_runs_finite = true
n_nonfinite = 0 in every run
```

The extreme numerical explosion seen in reconstruction round 1 did not recur.

Across the 80 runs:

```text
round 1 maximum MSE: 4.79e15
round 2 maximum MSE: 11.92

round 1 mean MSE: 8.87e13
round 2 mean MSE: 2.53
```

This comparison is diagnostic only because round 2 changes both the Jammer rule
and the execution horizon.

## Gate 2: matched terminal horizon — PASS

Every run completed exactly 100 modeled periods:

```text
min steps = 100
max steps = 100
mean steps = 100
```

Therefore every J=1/J=0 contrast and every adaptive/frozen contrast is now
evaluated at a common T.

Convergence remains available as a diagnostic. In this 80-run grid, 29 of 80
runs crossed the current convergence threshold before T, with first crossings
between periods 33 and 98. No run terminated at that crossing.

## Gate 3: Jammer strategy trajectory — PASS

The reconstructed Jammer obeyed the intended surveillance timing:

```text
refresh: t = 0, 5, 10, ...
hold:    t = 1-4, 6-9, ...
```

Within every five-period surveillance block, the segment-specific message mean
was exactly constant.

For K=1 in this diagnostic, the active-Jammer message means were finite:

```text
minimum message mean = 3.73
median message mean  = 4.73
maximum message mean = 22.91
```

The maximum is not imposed by clipping; it is generated by the explicit
one-step objective from the observed segment state.

The new `jammer_strategy_trajectory.csv.gz` output makes every message mean
traceable to the corresponding segment mean, segment dispersion, response gain,
and cluster size.

## Gate 4: dynamic effective-reliance measurement — PASS

The original structural-to-effective TV distance remains mechanically constant
within a fixed degree/epsilon regime because credibility adaptation permutes a
fixed rank-probability vector. It is retained only as a descriptive measure of
concentration relative to equal structural use.

The new dynamic Lambda measures respond to source-rank changes as intended.

Across adaptive runs:

```text
mean first-audit-to-terminal Lambda TV = 0.351
mean cumulative Lambda turnover        = 0.704
mean top-source-changed share           = 0.379
mean top-source switches per citizen    = 0.758
```

Across frozen runs, all four quantities were exactly zero.

The selected-period checkpoint output also shows the intended distinction:
adaptive Lambda moves away from the first post-audit network over time, whereas
frozen Lambda remains identical to it.

## Preliminary pattern check — not manuscript inference

The five-seed diagnostic is too small for substantive claims, but it is useful
for confirming that the reconstructed mechanisms generate non-degenerate
variation.

Matched mean Delta MSE (J=1 minus J=0) in this diagnostic:

```text
                     adaptive    frozen
elite_only             0.0160    0.0160
random_2               0.1943    0.1225
group_id              -0.2913    0.3941
extended               0.0413    0.0053
```

The large seed-to-seed variation in Random 2 and Group ID, and the negative
five-seed mean in adaptive Group ID, should not be interpreted before a much
larger matched-seed run.

A separate feature is already clear at the diagnostic level: sparse Random 2
and Group ID can have high MSE even in J=0 because truth-centered elite access
is structurally sparse. That is consistent with the new topology definitions
and makes corrective-pathway availability an important object for the
production design rather than a nuisance to be averaged away.

## Implication for the next gate

The reconstruction-round-2 mechanics now satisfy the intended computational
invariants:

- fixed terminal horizon;
- finite citizen states;
- objective-based finite Jammer strategy;
- scheduled surveillance with within-window message holding;
- dynamic effective-reliance measurement;
- exact frozen-reliance invariance after the first audit;
- matched four-environment topology.

The next simulation should therefore be a larger matched-seed pilot, not another
mechanical code reconstruction. The pilot should be used to determine the
production seed count, confirm the distribution of Delta MSE under sparse
networks, and inspect whether the chosen T is long enough across all four
environments and prior regimes.
